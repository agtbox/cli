# Contributing

`agtbox/cli` is the public distribution repository for the Agentbox CLI. Its
source is maintained and released from the Agentbox product repository so the
published package can be reviewed against the production contract.

Please use [GitHub Issues](https://github.com/agtbox/cli/issues) for bug
reports, security questions, and feature requests. Pull requests are not
accepted in this mirror; changes are reviewed and published by the maintainers.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of
opening a public issue.
